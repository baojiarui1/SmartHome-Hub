# Smart Home Hub (双芯 AIoT 智能家居网关)

本项目是一个基于 **ESP32-S3** 与 **STM32F103** 协同开发的高可靠智能家居中枢系统。项目采用“边缘计算 + 云端 AI”架构，实现了从自然语言语音交互到物理硬件控制的完整闭环。

## 🏗️ 系统架构

*   **ESP32-S3 (智能网关)**：搭载小智 AI (大语言模型)，负责语音交互与云端通信。基于 **FreeRTOS** 开发，采用 Queue 队列实现底层通信与业务逻辑的彻底解耦。
*   **STM32F103 (边缘节点)**：负责底层传感器（DHT11）数据采集与执行器（LED）控制。

## 🔗 核心通信协议

*   **自研 KLV 变长协议**：采用 `Key-Length-Value` 格式封装数据，并加入标准 **CRC-8** 校验。
*   **高可靠防御机制**：双端串口均手写状态机解析器，内置越界拦截、超时重置与异常丢弃机制，确保极端干扰下系统不死机、不误判。

## 🚀 核心特性

*   🛠️ **深度 RTOS 重构与双系统移植**：STM32 端从零手写移植 **FreeRTOS V10.4.6** 与 **RT-Thread Nano** 双内核。成功解决 SysTick 中断冲突、Keil 入口重定义等底层难题，通过消息队列实现采集与通信的异步解耦。
*   🎙️ **AI 语音控制 (MCP 协议)**：打通小智 AI 的 MCP 接入层。注册自定义 MCP 工具，使云端大模型具备直接控制下位机硬件（如照明灯）的能力。
*   ⏱️ **无阻塞异步告警防抖**：摒弃阻塞式延时，在 ESP32 端采用软件定时器实现报警状态机。在告警触发期间（4秒）不阻塞串口数据接收，实现平滑的 UI 锁定与恢复。
*   🔊 **毫秒级本地离线报警**：利用编译器机制将定制的音频流（.ogg）通过内联汇编直接内嵌至 Flash 内存。脱离云端 TTS 网络依赖，实现断网状态下的 0 延迟专属语音播报。

## 📂 仓库分支说明 (GitHub Branches)
本仓库包含完整的版本演进，你可以通过切换分支查看不同的底层架构实现：
*   `master` 分支：**STM32 裸机版** + ESP32 网关代码。
*   `stm32-freertos` 分支：STM32 节点基于 **FreeRTOS** 重构的多任务版本。
*   `stm32-rt-thread` 分支：STM32 节点基于 **RT-Thread Nano** 重构的多任务版本。
