本项目是基于esp32s3和stm32f103开发的智能家居项目

🏗️ 系统架构
ESP32-S3 (智能网关)：搭载小智 AI (大语言模型)，负责语音交互与设备调度。基于 FreeRTOS 开发，采用 Queue 队列与业务逻辑解耦，并通过软件定时器实现无阻塞的告警防抖。

STM32F103 (下位机)：基于标准库开发，负责 DHT11 传感器数据采集与执行器控制。

🚀 核心特性
自定义高可靠协议：采用 KLV（键-长度-值）变长数据帧，结合 CRC-8 校验，确保数据传输零误判。

AI 语音控制 (MCP)：接入小智 MCP 协议，实现通过自然语言直接控制下位机灯光开关。

边缘报警联动：下位机实时采集温度，触发阈值后通过串口上报，ESP32 立即触发本地语音播报与屏幕 UI 弹窗。

状态机与防御式编程：双端串口均采用状态机解析，消灭所有魔法数字，内置越界拦截，保证系统不死机。
